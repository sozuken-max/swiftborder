## What graders care about (implication for SwiftBorder)

- **Methods and metrics** — evaluation protocols, honest targets vs measured results.
- **Runnable pattern recognition system** — demoable MVP, not only cloud sketches.
- **Final report** — tools/techniques; system design / models; performance; findings and discussion.
- **Presentations** — goals, data, techniques/tools, progress (first); full methods + metrics of success (final video, ~10–15 minutes).
- **Peer review** + short **individual reflection** (contribution, learning, workplace transfer).

## Project requirements (module)

- Team max 5; Canvas group enrolment.
- Practical application showing value of pattern recognition / ML.
- Develop, integrate, and demonstrate **at least three** of:
  - Supervised / unsupervised learning scenarios
  - Machine learning / deep learning techniques
  - Hybrid ML / ensemble approach
  - Intelligent sensing / sense-making techniques

## Deliverables (team)

- Runnable pattern recognition system
- Datasets
- Final report (tools, design/models, performance, findings)
- Code / model files / supporting docs as needed
- Final video presentation (~10–15 min) + slides for both presentations
- One team ZIP to Canvas (except individual report)

## Additional (per member)

- 1–2 page individual reflection
- Peer review via the course peer-review system
